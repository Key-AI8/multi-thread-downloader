# 多线程下载器

基于浏览器 HTTP Range 请求实现的多线程并行下载工具，支持 16 / 32 / 64 / 256 / 512 线程并行下载。

## 功能特性

- 支持 16 / 32 / 64 / 256 / 512 线程并行下载
- 基于 HTTP Range 请求实现真正的多线程并行
- 实时显示每个线程的下载进度和状态
- 自动重试失败的线程（最多 3 次）
- 下载速度、已用时间、剩余时间实时统计
- 下载历史记录（本地保存）
- 自动从文件名或 Content-Disposition 提取文件名
- 深色主题界面，响应式设计

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React 图标

## 使用说明

1. 输入文件下载链接
2. 选择线程数（16 / 32 / 64 / 256 / 512）
3. 点击「开始下载」
4. 下载完成后文件会自动保存

> **注意：** 服务器需支持 HTTP Range 请求和 CORS 跨域才能使用多线程下载。浏览器对同一域名的并发连接数有限制（通常为 6 个），超出部分将自动排队。

## 开发

```bash

npm run dev
```
